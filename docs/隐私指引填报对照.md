# 《用户隐私保护指引》后台填报对照清单

> 用途：微信公众平台「设置 → 服务内容声明 → 用户隐私保护指引」填报对照。
> 与代码实际行为对齐（填报口径 = 代码真实收集口径，避免因声明不符被驳回）。
> 页内展示文案已内置：小程序「我的 → 设置 → 隐私政策」（与本文档同源，修改需两处同步）。

## 需要声明的信息收集项

| 后台收集类型 | 对应代码行为 | 使用场景/目的 |
|---|---|---|
| 注册账号（手机号） | 登录（账号密码/微信绑定），`user_wechat_bindings.openid` | 登录与身份识别、订阅消息下发 |
| 收集姓名 | 注册申请 `real_name`、用户资料 | 实名学籍展示、成绩归属 |
| 收集学校/年级信息 | 注册申请 district/school/grade | 学籍归属、测评范围 |
| 收集身份证号（片段） | 注册时完整号仅用于身份核验，**仅存后四位**（`id_card_last4`） | 学籍身份核验（最小化收集，需在指引中如实表述） |
| 学习与测评记录 | 答题/判题/错题/积分/成就/连胜 | 学情分析、个性化练习 |
| 微信 OpenID | 微信登录绑定、订阅消息 | 免登、连胜提醒下发 |

## 不收集 / 不做的（同样要在指引里如实说明）

- 不获取微信昵称/头像之外的社交关系与相册、位置、麦克风等敏感接口；
- 不向第三方共享、不出用于商业营销；
- 积分/成就/商店为虚拟体系，不涉及支付与现金交易。

## 未成年人合规要点

- 用户主体为小学生（多为不满 14 周岁儿童）：注册审核制由学校管理员核验，
  指引需表述"已按有关规定取得监护人同意"；建议后台指引文案含"家长可通过
  绑定关系查看孩子数据、可联系学校管理员更正/删除"。
- 小程序端**不启用身份证登录**（仅 web），最小化敏感信息收集。
