## 角色层级与权限

```
municipal_admin (市级总管理员, admin)
   └─ base_school_admin / municipal_school_admin（基地校 / 市直属学校管理员）
        └─ district_admin (区级管理员: 云岩/南明/观山湖/白云/花溪/乌当)
             └─ school_admin (校级管理员)
                  └─ teacher (教师)
                       └─ student (学生) / parent (家长)
```

**账号创建规则**:
- 每一级管理员可以创建下一级账号；教师与学生不能创建账号
- 后端会从市级总管理员的用户列表中排除 `system_admin` / `municipal_admin`（含自身），避免越权操作同级账号

## 测试建议

### 管理员流程
1. **市级总管理员**（`admin`）：用户管理（筛选/新建/编辑/重置密码）、题库治理、审批中心、权限管理、区域数据统计
2. **区级管理员**（如 `yunyan_admin`）：所辖区县的学校与师生数据、区级统计
3. **校级管理员**（`school_admin_01`）：本校师生管理

### 教师流程
推荐 `teacher_yy_ps_math`（数据最全）：
1. 题库管理：创建题目（单选/多选/判断/填空/主观），校级题库直接发布，市级题库保存草稿后提交审核
2. 活动管理：创建练习/测评活动（时间限制类型：无限制/定时/计时），发布并组卷
3. 评卷管理：批改主观题、完成评卷
4. 数据分析：查看能力维度统计

### 学生流程
推荐 `13800138003`（张小明）：
1. 练习中心：开始练习、答题（自动保存）、提交
2. 测评中心：报名/参加测评、定时活动倒计时
3. 成绩/错题集/学习统计/成就/积分：查看结果与激励数据

### 家长流程
`parent01` 登录后选择孩子，查看学情报告。
