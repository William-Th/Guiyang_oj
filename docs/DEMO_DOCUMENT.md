### 1.5 题库管理（管理员+教师共用）

**路径**：`/admin/question-bank` 或 `/teacher/question-bank`

![题库列表](screenshots/09_admin_question_bank.png)

![创建题目](screenshots/10_admin_question_create.png)

**支持的 7 种题型**：

| 题型 | 标识 | 答题交互 | 判题方式 |
|------|------|---------|---------|
| 单选题 | `single` | Radio 单选 | 自动判题 |
| 多选题 | `multiple` | Checkbox 多选 | 自动判题 |
| 判断题 | `true_false` | 对/错选择 | 自动判题 |
| 填空题 | `blank` | 文本输入 | 自动判题 |
| 编程题 | `code` | 代码编辑器 | 判题服务沙箱评判 |
| 匹配题 | `matching` | 左右配对 | 自动判题 |
| 问答题 | `essay` | 文本域 | 教师手动评分 |

**题目属性**：

- 难度等级：简单 (easy) / 中等 (medium) / 困难 (hard)
- 适用科目：数学、信息科技
- 适用年级：一年级 ~ 高三（按科目不同有所限制）
- 题库范围：测评题库、市级练习题库、区级练习题库、校级练习题库

**富文本题干**：题干编辑采用 wangEditor 富文本编辑器（前后端 DOMPurify/sanitize-html 全链路消毒），支持加粗、列表、图片等排版，学生端按同样式渲染。

**题目生命周期**：

```
创建草稿 → 提交审核 → 审核通过/驳回 → 发布入库 → 停用
```

**题库范围说明**：

| 范围 | 说明 | 可见性 |
|------|------|--------|
| 测评题库 (assessment) | 区级测评专用 | 区级管理员管理 |
| 市级练习题库 (practice_municipal) | 全市练习 | 市级管理员管理 |
| 区级练习题库 (practice_district_XX) | 本区练习 | 区级管理员管理 |
| 校级练习题库 (practice_school_N) | 本校练习 | 校级管理员管理 |

### 1.7 测评活动管理

**路径**：`/admin/assessments`

![测评活动管理](screenshots/12_admin_assessments.png)

**活动类型**：

| 类型 | 标识 | 说明 |
|------|------|------|
| 测评 | `assessment` | 正式考试，有严格时间限制 |
| 练习 | `practice` | 自主练习，可配置重做 |

**创建活动流程**：

1. 选择类型（测评/练习）和科目
2. 选择年级（一年级 ~ 高三）和能力等级（L1 ~ L7）
3. 设定时间范围和时长限制（限时/不限时）
4. 设置及格分数和总分
5. 选择发布范围（市级/区级/校级）
6. 配置是否允许重做及最大尝试次数
7. 提交后进入组卷环节

**活动状态流转**：

```
草稿 → 已发布 → 进行中 → 已结束
```

**组卷功能**（`/admin/assessments/:id/paper`）：

- 从题库按条件筛选题目（题型、难度、科目）
- 添加到试卷并设置分值
- 支持手动选题和自动抽题
- 预览试卷总分和时间配置

## 六、系统架构与技术亮点

### 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | React 18 + TypeScript + Ant Design 5 + Redux Toolkit + Vite |

| 判题 | 独立 judge-service 服务，沙箱执行代码 |
| 部署 | Docker Compose + Nginx 反向代理 |
| 图表 | Recharts（柱状图、条形图） |
| 测试 | Playwright (E2E) + Jest (单元/API) |

### 服务架构

```
浏览器 ──→ Nginx(:8080) ──→ Frontend(:3100, 容器内 :80)
                        ──→ Backend(:3003) ──→ PostgreSQL(:5433)
                                             ──→ Redis(:6380)
         Judge Service(:3002，沙箱执行)
开发调试：Vite Dev Server(:3000) → 代理后端
```
